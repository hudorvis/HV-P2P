HV P2P v26.08.31.09 -> v26.08.31.10 CHANGE AUDIT
==================================================

Purpose
-------
v26.08.31.10 is a corrective build revision after the issued v26.08.31.09 source
pack failed the GitHub macOS backend regression. It intentionally contains no
new operator-requested features or visual redesigns.

Functional backend correction
-----------------------------
- Virtual Position Source now sets the local `_safety_servo_inhibited` state as
  part of the mode transition itself, independent of whether smoke-test mode has
  disabled physical hardware I/O.
- Real hardware behavior is unchanged: with real I/O active, Virtual continues
  to inhibit the physical W1P using STOP / SW_SRVON 0 and never sends non-zero VEL.

Regression correction
---------------------
- The Virtual motion backend test now establishes its own known joystick,
  direction, calibration and service state before asserting simulated motion.
- This prevents unrelated earlier regression cases from altering the sign/state
  expected by the Virtual test.

Version/build metadata
----------------------
- Application/firmware release identity advanced from v26.08.31.09 to
  v26.08.31.10.
- GitHub workflow artifact names, source directory names, firmware identity
  tokens, HMI required version, macOS bundle build version and release packaging
  names were advanced consistently to .10.

Intentionally unchanged
-----------------------
- Locked SRVR Run QML layout and interaction model.
- Locked SRVR Setup QML layout and interaction model.
- Free-D UI/behavior other than inherited prior fixes.
- Log UI.
- CTRL-TS operator UI.
- Physical W1P motion protocol and control semantics.
- All v26.08.31.07/.08 safety/build hardening.
